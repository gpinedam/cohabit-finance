1. Nombre del proyecto
Cohabit Finance
Aplicación de gestión de gastos compartidos para parejas.

2. Descripción
Cohabit Finance permite a dos personas registrar, dividir y hacer seguimiento de sus gastos en común. El sistema soporta múltiples estrategias de división (proporcional al sueldo, 50/50, "lo pago yo" y personalizado), autenticación con PIN para acceso rápido en móvil, y visualización de balances y deudas en tiempo real.

El foco es la usabilidad en web móvil: flujo de entrada de gasto directo desde la pantalla principal, navegación por tabs inferiores y diseño optimizado para pantallas pequeñas.
